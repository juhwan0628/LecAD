## 프로젝트 소개

온라인 강의에는 그래프, 수식, 표와 같은 시각 자료가 자주 등장합니다. 그러나 교수자가 **“이 그래프를 보시면”**, **“여기에서”**라고 설명할 때 시각장애 학습자는 화면에서 무엇을 가리키는지 파악하기 어렵습니다.

**LecAD(Lecture Audio Description)**는 이러한 시각 정보의 공백을 줄이기 위해 강의 영상에서 음성해설이 필요한 시점을 찾아, 화면과 발화 맥락에 맞는 설명을 생성하고 영상에 삽입하는 시스템입니다.

성균관대학교 **2026 Co-Deep Learning 프로젝트**로 진행했으며, 실제 시각장애 학생들의 의견을 바탕으로 음성해설의 제공 시점과 설명 방식을 탐구했습니다.

## 작동 원리

```mermaid
flowchart LR
    A[강의 영상] --> B[음성 전사 및 슬라이드 정보]
    B --> C[시각적 지시 표현 감지]
    C --> D[화면 프레임 및 발화 맥락 수집]
    D --> E[VLM 화면 분석]
    E --> F[음성해설 문장 생성]
    F --> G[TTS 음성 합성]
    G --> H[음성해설이 삽입된 강의 영상]
```

연구에서는 음성해설의 **제공 시점(트리거)**을 세 가지 방식으로 설계했습니다.

| 트리거 | 작동 방식 |
| --- | --- |
| **슬라이드 전환** | 새로운 슬라이드로 넘어갈 때 화면 전환을 알리고 필요한 시각 정보를 전달 |
| **지시 표현** | “여기를 보시면”, “이 그래프”처럼 특정 화면 요소를 지칭하는 발화를 감지해 설명 |
| **On-demand** | 학습자가 필요한 순간 직접 음성해설을 요청 |

현재 저장소의 Python 파이프라인은 **지시 표현 기반 오프라인 영상 생성**을 중심으로 음성 전사·슬라이드 메타데이터, VLM, TTS, FFmpeg를 연동합니다.

## 현장 평가

2026년 6월 14일 **서울맹학교**에서 시각장애 중·고등학생 **7명(전맹 5명, 저시력 2명)**을 대상으로 파일럿 스터디를 진행했습니다. 그래프, 수식, 도표가 포함된 과학 강의 영상으로 슬라이드 전환, 지시 표현, 사용자 요청 기반 음성해설 방식에 대한 의견을 수집했습니다.

**주요 발견**

- 슬라이드 내용에 대한 긴 해설 없이도 **전환 사실을 알려주는 것**이 유용했습니다.
- 그래프·수식 등 시각 요소가 많은 수학·과학 과목에서 음성해설의 필요성이 두드러졌습니다.
- 지나치게 상세한 설명보다 **간결하고 핵심적인 설명**을 선호했습니다.
- **지시 표현 기반 트리거**에 대한 반응이 가장 긍정적이었습니다. 반면 On-demand 방식은 학습자가 언제 설명을 요청해야 할지 판단해야 하는 부담이 있었습니다.

이러한 결과를 바탕으로 LecAD는 모든 장면을 설명하기보다 **설명이 필요한 순간에 필요한 정보만 전달하는 방식**에 초점을 맞췄습니다.

## 기술 구현

Python 기반의 모듈형 처리 파이프라인으로 구성했습니다.

```text
강의 영상 + transcript.json + slides.json
             │
             ▼
       지시 표현 탐지
             │
             ▼
    프레임 추출 및 발화 맥락 구성
             │
             ▼
     VLM 관련성 판단 및 설명 생성
             │
             ▼
          TTS 합성
             │
             ▼
      FFmpeg 음성해설 삽입
             │
             ▼
         결과 MP4
```

**핵심 기술:** Python · Whisper 기반 전사 데이터 · VLM · TTS · FFmpeg · 타임스탬프 기반 편집 · JSON 매니페스트

해설은 교수자의 관련 발화가 끝난 시점에 삽입하며, 음성해설이 재생되는 동안 해당 화면을 유지해 기존 강의 설명의 흐름을 보존합니다.
