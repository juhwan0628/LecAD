# LecAD
시각장애 학생의 강의 영상 접근을 위한 AI 기반 음성해설 자동 삽입 시스템

성균관대학교 Co-Deep Learning 프로젝트 · 2026.03–07  
[2026-1 SKKU Co-Deep Learning Award](https://www.spressnews.com/news/articleView.html?idxno=138550)

## 소개

강의 영상에서 교수자가 “여기를 보시면”, “다음 그래프는”이라고 말할 때 화면을 볼 수 없는 학생은 설명 대상을 놓치기 쉽습니다. 특히 그래프·수식·도표처럼 화면 읽기 프로그램만으로 파악하기 어려운 자료에서 정보 격차가 발생합니다.

LecAD는 강의 영상의 시각 정보를 분석해 필요한 시점에 음성해설을 삽입하는 프로젝트입니다. 강의 음성의 지시 표현, 슬라이드 전환, 학습자 요청을 해설 제공 시점으로 설계했습니다.

## 시스템 구성

```mermaid
flowchart LR
    A["강의 영상"] --> B["전사·슬라이드 분석"]
    B --> C["해설 시점 탐지"]
    C --> D["프레임·발화 맥락"]
    D --> E["VLM 설명 생성"]
    E --> F["TTS"]
    F --> G["영상 삽입"]
```

| 해설 방식 | 내용 |
| --- | --- |
| 슬라이드 전환 | 슬라이드가 바뀐 시점을 알리고 새 화면을 설명 |
| 지시 표현 | “이 그래프”, “여기를 보시면” 등 발화의 시각적 대상을 설명 |
| On-demand | 학생이 요청한 시점의 화면을 설명 |

이 저장소에는 지시 표현 탐지부터 VLM 분석, TTS 합성, FFmpeg 영상 출력까지 이어지는 Python 파이프라인을 담았습니다. 음성해설은 관련 발화가 끝난 뒤 삽입하고, 해설 중에는 해당 화면을 유지합니다.

## 현장 평가

2026년 6월 14일 서울맹학교에서 시각장애 중·고등학생 7명(전맹 5명, 저시력 2명)을 대상으로 파일럿 스터디를 진행했습니다. 그래프와 수식이 포함된 과학 강의 영상으로 세 가지 해설 방식을 비교하고 의견을 수집했습니다.

참여 학생들은 슬라이드 전환 자체를 알려주는 기능, 수학·과학 자료의 간결한 해설을 유용하게 평가했습니다. 지시 표현을 감지해 해설하는 방식에 대한 반응이 가장 긍정적이었고, On-demand 방식은 해설을 요청할 타이밍을 스스로 판단해야 한다는 어려움이 있었습니다.
